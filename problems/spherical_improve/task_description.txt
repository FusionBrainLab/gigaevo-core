SPHERICAL CODES — IMPROVE A WARM-START CONFIGURATION ON ANY (n, d)

Objective: place n unit vectors in R^d that minimize the maximum pairwise inner product
  mu(X) = max_{i<j} <x_i, x_j>        (lower mu is better)

Regime: the grader never cold-starts. It seeds each evaluation with a strong
best-known configuration and measures how much improve() and perturb() lower mu
below that baseline. You are floored at the baseline — non-improvement scores
zero, never negative.

Generality: the class must work for any n >= 2 and any d >= 2. No hardcoded
dimensions, point counts, shapes, or branches tied to a single (n, d).

THE GRADER (per configuration)
- current = best-known config;  baseline = mu(current)
- improve(current): accept the result if it lowers mu
- then R rounds of B steps:
    perturb(current, intensity) -> improve(result) -> accept only if it lowers mu
  intensity sweeps high to low across each round (geometric schedule)
  acceptance is monotone: mu can only decrease; ties accepted, regressions discarded
- per-config score = relative reduction of mu vs the baseline, clamped at zero
A raised exception costs only that one call (improve in stage A, or that one
perturb->improve pair in stage B). The run aborts only if no configuration ever
returns a valid array.
There is a generous per-configuration time budget. Spend it on depth: more
restarts, finer convergence, and more perturb->improve rounds all push mu lower.
The grader keeps the best configuration any completed improve()/perturb() call
returns, so a longer, deeper search never costs score; prefer an anytime
optimizer that keeps lowering mu over one that returns early.

HARD CONSTRAINTS
- output shape exactly (n, d)
- unit rows: max_k | norm(x_k) - 1 | <= 1e-12   (float32 round-off ~1e-7 fails; use float64)
- no NaN, no Inf

REQUIRED CLASS — exact signature

import numpy as np

class Improver:
    def __init__(self, n: int, d: int, seed: int = 0): ...
    def generate_config(self, seed=None) -> np.ndarray: ...      # (n, d) unit-norm; interface only
    def improve(self, points: np.ndarray, seed=None) -> np.ndarray: ...
    def perturb(self, points: np.ndarray, intensity: float, seed=None) -> np.ndarray: ...

def entrypoint():
    return Improver

- improve: refine a configuration toward lower mu; return (n, d) unit-norm.
- perturb: structured escape from a local optimum, scaled by intensity in [0, 1];
  return (n, d) unit-norm. Larger intensity means a larger structural move.
- generate_config is part of the interface; the grader warm-starts from the
  best-known config, not from generate_config.

Perturbation ideas that tend to work: target the active set (the pairs realizing
the current maximum); relax through a smooth surrogate of the max (LogSumExp,
Riesz s-energy) then sharpen; move on the sphere geometry (tangent steps,
geodesic updates, subset rotations); orchestrate these by intensity.
