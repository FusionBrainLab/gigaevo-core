**TASK DEFINITION – SECOND AUTOCORRELATION INEQUALITY OPTIMIZER**

**Challenge:** Implement a Python class that maximizes the autocorrelation ratio $C$ of a non-negative function $f$ sampled on a length-$N$ grid.

**Specific Benchmark:** $N=50000$.
**General Requirement:** The code must be valid for any grid resolution $n \ge 100$.

**PROBLEM SPECIFICATION**
1.  **The function f (Config):**
    *   A 1-D array of $n$ entrywise non-negative real samples, $f \in \mathbb{R}_{\ge 0}^{n}$, of a function on an interval.
    *   $n$ is the grid RESOLUTION and is fixed by the constructor. It is not yours to change.
2.  **The autoconvolution:**
    *   $g = f * f$, the full discrete autoconvolution of $f$ with itself (length $2n-1$), computed by FFT.

**OBJECTIVE FUNCTION**
Maximize Fitness: $C = \dfrac{\lVert f * f \rVert_2^2}{\lVert f * f \rVert_1 \cdot \lVert f * f \rVert_\infty}$.
*   $C$ is scale-invariant: multiplying $f$ by any positive constant leaves $C$ unchanged, so only the SHAPE of $f$ matters.
*   $C \in (0, 1]$. The constant seed $f = \mathbf{1}$ gives $C = 2/3$ at every resolution; the search climbs from there.
*   *Reference to beat:* the best published value is $C \approx 0.96102$. That is a target, not a starting point you are handed — you build $f$ yourself.

**CONSTRAINTS**
1.  **Non-negativity:** Every entry of the returned array must satisfy $f_i \ge 0$.
2.  **Length:** The returned array must have exactly $n$ entries.
3.  **Finiteness:** All entries must be finite (no NaN, no Inf), and $f$ must not be all zeros.

**EVALUATION BUDGET**
One evaluation gives your class ONE total wall-clock budget. The evaluator calls it repeatedly until that budget is spent, independently validates every array it hands back, and keeps the best valid one. Nothing else is rationed, so the cost of a call is a real cost: a cheap call buys more calls, and an expensive call has to earn its keep by being better. Time spent inside one call is time no other call can use.
